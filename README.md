# TeamSync

TeamSync is a modern project management web application built using React and Vite.

## Features

- User Login & Signup
- Admin Portal
- Project Management
- Task Management
- Team Member Management
- Dark / Light Mode
- Notifications
- Responsive UI
- Protected Actions Without Login
